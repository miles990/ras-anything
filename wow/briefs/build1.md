## Pipeline (all must work end-to-end, offline)
1. **scan -- <cmd>**: run workload clean (record per-function call counts for top-level functions in the user's project files; boundary calls attributed to the innermost user function on the stack), then N seeded chaos runs. Static AST signals per function: boundary call without `timeout=`; no retry loop; `except:`/`except Exception: pass|return None` swallowing; non-idempotent write (POST/PUT/PATCH/DELETE) in a retry or with no Idempotency-Key; raise without context/`from`; `open()` not in `with`; logging absent. Dynamic signals: crash/hang/wrong-result rate of the function under chaos. Score = risk × exposure × hardenability (hardenable = top-level function or @staticmethod in an importable module, args/returns JSON/pickle-able; not in `__main__` unless guarded by `if __name__ == "__main__"`). Print a beautiful ranked table (ids like `weather.fetch_forecast`), each with ≤1-line why + verdict `harden it` / `✗ <reason>`. Save `.ras/scan.json`.
2. **harden [id] [--agent claude|codex|<shell cmd reading stdin>]**: re-run the workload with a recorder: up to 500 calls of the target: args, kwargs, return (or exception type+message), and the ordered boundary I/O it did (VCR cassette: request method/url/body-hash/timeout passed → status/headers/body or exception). Write `.ras/hardens/<id>/{calls.pkl or .jsonl, TASK.md, hardened.py}`. hardened.py stub = original source of the function copied in (via inspect) for the agent to edit. TASK.md: the contract (same happy-path results, bounded latency budget, retries only transient, idempotency, declared fallback via a module constant `RAS_FALLBACK = {...}` or `None`, structured errors via runtime helpers, don't touch recordings, run `ras-anything verify <id>`). `--agent claude` runs `claude -p --permission-mode acceptEdits` in that dir with TASK.md on stdin; `codex` runs `codex exec --full-auto`; anything else is a shell command fed TASK.md on stdin.
3. **verify [id]**: (a) happy replay: boundary served ONLY from the cassette (no network); hardened(*args) must equal recorded result for every call (exceptions: same type). (b) chaos replay: fixed fault matrix applied per boundary attempt, deterministic seed: `timeout/hang` (if caller passed timeout t → after t raise socket.timeout/URLError(timeout); if no timeout → block for HANG_CAP then raise a `BaseException` subclass `ChaosHang` so `except Exception` can't hide it; counts as hang), `refused` (ConnectionRefusedError/URLError), `http5xx` (HTTPError 503), `http429` w/ Retry-After, `slow` (adds latency, then correct response), `truncated` (body cut → parse errors), `outage` (dependency down for K consecutive attempts then recovers). Use a **virtual clock** if you can (patch time.sleep/time.monotonic for the replayed function so hangs/backoff cost no wall time and latency numbers are deterministic) — otherwise scale real sleeps down and say so. Run original and hardened over identical fault schedules. Classify each logical call: `ok` (== happy result), `degraded` (== declared fallback), `wrong` (other value — silent wrong data!), `error` (exception within budget), `hang` (ChaosHang or latency > budget). (c) gates: happy 100% equal; no `wrong`; no hang; p99 ≤ budget; duplicate non-idempotent side effects ≤ original (count POST/PUT/PATCH/DELETE attempts per logical call lacking Idempotency-Key header); availability (ok+degraded)/total strictly > original. Print a crisp verdict table and the first failing call with its fault schedule when failing. Save `.ras/hardens/<id>/verify.json`.
4. **enable/disable [id]**: append to the function's module one block between `# >>> ras-anything:<id> >>>` / `# <<< ras-anything:<id> <<<` that (unless env `RAS_ANYTHING_DISABLE=1`) imports the hardened function from a copy placed at `<pkgdir>/_ras_hardened/<name>.py` (or loads `.ras/hardens/<id>/hardened.py` by path) and rebinds the module name; disable removes it byte-for-byte (verify sha256 of file before enable == after disable; store in `.ras/state.json`). Refuse enable unless verify passed for the current hardened.py hash.
5. **bench -- <cmd>** [--seeds N, default 20]: whole-app runs, interleaved original (RAS_ANYTHING_DISABLE=1) vs hardened, chaos injected live at the boundary with the same seed per pair (real dependency behind it — the examples run their own local upstream). Per run: exit code, stdout equal to the clean-run stdout (or declared degraded marker), wall time. Report: app availability % (runs with correct-or-degraded output and exit 0), crash %, p50/p99 wall, duplicate side effects, plus per-function stats from the runtime. Save `.ras/bench.json`.
6. **report**: `RAS-REPORT.md` + `ras-card.svg` (hand-written SVG, professional: dark+light-safe, clear hierarchy, before→after availability bar starting at 0, error rate, p99, dup side-effects, fault model + seeds + host in small caption; no chart junk). Only measured numbers.
7. **doctor**: python ≥3.10, claude/codex on PATH, git clean, `.ras` writable, requests present?.
8. **go --agent X -- <cmd>**: scan → harden top hardenable → verify (if fail, re-run agent once with the failure appended) → enable → bench → report.
9. **mcp**: stdio JSON-RPC 2.0 MCP server (initialize, tools/list, tools/call) exposing ras_scan, ras_harden, ras_verify, ras_enable, ras_disable, ras_bench, ras_report, ras_status. Stdlib only.
10. Claude Code plugin: `.claude-plugin/plugin.json` + `.claude-plugin/marketplace.json`, `commands/ras.md`, `skills/ras-anything/SKILL.md` (teaches the loop like fast-anything's skill).
11. `ras_anything/runtime.py`: `call_with_timeout`, `retry(fn, *, attempts, base, cap, budget_s, retry_on, sleep=time.sleep)` with full jitter (AWS: sleep = random(0, min(cap, base*2**n))), honoring Retry-After; `CircuitBreaker(fail_threshold, cooldown_s)`; `RasError(message, *, cause, context, trace_id)`; `log_event(event, **fields)` JSON line to stderr with trace id. Seedable randomness for determinism under verify.
