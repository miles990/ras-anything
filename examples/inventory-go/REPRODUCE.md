# Reproduce: inventory-go (Go)

Everything runs offline: `go run .` starts its own warehouse HTTP server (`httptest.NewServer`)
on a free localhost port, honouring `Idempotency-Key` on `POST /reserve`. Stock lookups go over
`http.Get`, restock reservations go over `http.Post`, and warehouse bin tags are generated by an
external CLI subprocess (`sh -c ...` via `exec.Command`). Faults are injected at the app's side
of the boundary; the upstream is always healthy.

Host for the committed numbers: Linux x86_64, Go 1.27.3, Python 3.13 (orchestrator), 2026-11-23 (Asia/Taipei).

```sh
# from the repo root
python3 -m venv .venv && . .venv/bin/activate && pip install -e .
cd examples/inventory-go
go run .                                        # 6 SKUs, deterministic JSON output

ras-anything scan -- go run .
ras-anything harden warehouse.FetchStock
ras-anything harden warehouse.ReserveStock
ras-anything harden warehouse.AuditTag
ras-anything verify warehouse.FetchStock
ras-anything verify warehouse.ReserveStock
ras-anything verify warehouse.AuditTag
ras-anything enable warehouse.FetchStock
ras-anything enable warehouse.ReserveStock
ras-anything enable warehouse.AuditTag
ras-anything bench --seeds 20 --rate 0.1 --slo "availability=95.0,p99=3s,error_rate=5%" -- go run .
ras-anything report --title inventory-go
```
